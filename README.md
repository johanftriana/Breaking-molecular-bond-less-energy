# Breaking-molecular-bond-less-energy
Code and data used in "The infrared vacuum reduces the laser energy needed to break molecular bonds of simple molecules", by Johan Triana and Felipe Herrera - Submitted

Repository Contents:

- Figure 2 Data: Potentials and dipole moment functions. 
- Figures 3 Data: Photodissociation probabilities for the C-O stretching mode of CO2 molecule.
- Figure 4 Data: Photodissociation probabilities for the O-H stretching mode of H2O molecule.
- Figure 5 Data: Time-Dependent Photodissociation probabilities for the O-H stretching mode of H2O molecule.
- Figure 6 Data: Density of polariton states for the O-H stretching mode of H2O molecule.
